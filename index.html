      How it works

      This demo illustrates the report and its evidence links. The example findings were written for the demo.

      Bounded collection
      The local app collects up to 75 newest top-level comments from one video and screens them for English.
      Local sentiment
      A CPU model and simple rules assign five outcomes. Uncertain is available when a label would overstate what the text says.
      Recoverable reports
      A background worker saves analysis progress and reports. The page reopens a saved analysis by ID after refresh.
